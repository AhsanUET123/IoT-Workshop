
Arduino & ESP32 Hands-on Workshop ki preparation ke liye tamam participants se request hai ke apne laptops par Arduino IDE install aur configure kar lein.

Hum workshop mein different practical projects perform karenge, isliye please neeche diye gaye instructions follow karein.

*1. SOFTWARE REQUIREMENTS*

Please install:

• Arduino IDE 2.x
• USB data cable for Arduino UNO and ESP32
• Required USB drivers, if your board's COM port is not detected.

Official Arduino IDE download:
https://www.arduino.cc/en/software

*2. ARDUINO IDE LIBRARIES*

Arduino IDE open karein:

Sketch → Include Library → Manage Libraries

Search and install the following libraries:

1. *Servo* – For servo motor and automatic gate projects.
2. *DHT sensor library* by Adafruit – For DHT11 temperature and humidity sensor.
3. *Adafruit Unified Sensor* – Dependency for DHT sensor library.
4. *ThingSpeak* – For sending sensor data to ThingSpeak cloud.
5. *Blynk* – For ESP32 IoT projects using Blynk platform.

*Important:* Har project ke liye additional library required nahi hoti. Basic LED Blink, PWM, FC-28 Soil Moisture, IR Sensor and Buzzer projects Arduino's built-in functions se perform ho sakte hain.

*4. ESP32 BOARD SETUP*

To use ESP32 with Arduino IDE, follow these steps:

*Step 1:* Open Arduino IDE.

*Step 2:* Go to File → Preferences.

*Step 3:* In Additional Boards Manager URLs, add this link:

https://espressif.github.io/arduino-esp32/package_esp32_index.json

*Step 4:* Go to Tools → Board → Boards Manager.

*Step 5:* Search for "ESP32".

*Step 6:* Install "esp32 by Espressif Systems".

*Step 7:* Restart Arduino IDE.

*Step 8:* Connect ESP32 to your laptop using a USB data cable.

*Step 9:* Select:
Tools → Board → esp32 → ESP32 Dev Module.

*Step 10:* Select your ESP32 COM port from Tools → Port.

Your ESP32 is now ready to use with Arduino IDE.

*5. IMPORTANT INSTRUCTIONS*

• Make sure Arduino IDE is installed before attending the workshop.
• Install the libraries mentioned above.
• Keep your Arduino UNO and ESP32 boards ready.
• Bring your USB data cables.
• Bring your sensors, LEDs, resistors, jumper wires and breadboard, if available.
• Do not connect 5V directly to ESP32 GPIO pins. ESP32 GPIO operates at 3.3V logic.
• For servo motors, use an appropriate stable power supply and common GND.
